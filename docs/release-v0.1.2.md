# OMP Mobile 0.1.2

- Match OMP's colorful Markdown roles: magenta H1, bold and italic; yellow H2 and table headers; blue H3–H6; green inline code. Mobile keeps its dark-surface palette, numeric accents and fenced-code rendering.
- Expand phone-side session control with live `ask`, approval, plan-review and terminal-owned dialogs, plus richer runtime notices and result cards.
- Improve long-session reading and recovery with complete message/image loading, older-history recovery, stable scroll anchors and compact transcript updates.
- Make composer and session state more reliable across reloads, reconnects, polling and continuations; reduce background transfers with validated compressed assets, lazy-loaded renderers and bounded caches.

Source release. GitHub provides source archives for the tag; no native binaries or app-store packages are included. Follow the [quick setup](../README.md#quick-setup) and review [UI coverage and host limits](guide.md#transcript-and-interaction-coverage) before upgrading live sessions. Restart existing OMP sessions to load the updated Mobile extension.
