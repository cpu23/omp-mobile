# OMP Mobile 0.1.1

- Cleaner pending-message cards: queued text and status, without repeated help or API limitation notices.
- Session dialogs keep the sidebar open when confirming or cancelling a stop.
- Improved initial session loading, activity details, directory completion and shared session-limit settings since 0.1.0.

Source release; no native binaries or app-store packages. Follow the [quick setup](../README.md#quick-setup).
